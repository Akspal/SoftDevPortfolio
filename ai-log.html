AI Engineering Log

Documenting how AI assistance was leveraged during the redesign and implementation of Portfolio 2.0.

What I Asked Why I Asked What Did AI Give Me? What Did I Change? Did It Work?
"How do I set up CSS custom variables to handle a clean dark/light mode toggle with smooth transitions?" To implement Part 3 requirements across all pages cleanly without duplicated CSS rules. A CSS snippet defining :root and [data-theme="dark"] color variables. Adjusted exact color hex codes to ensure background-to-text contrast complied with accessibility guidelines. Yes, worked immediately when paired with JS switching the data-theme attribute on the <html> element.
"How do I filter project cards in vanilla JS using data attributes without reloading the page?" To implement Part 5 project filtering capability. A script iterating over cards with querySelectorAll and applying display: none via CSS classes. Modified filtering logic to handle multiple tags per project by splitting class strings in data-category. Yes, verified through user testing that clicking tags correctly hides and shows cards instantly.
"How do I build an accessible modal pop-up in plain JavaScript and CSS?" To satisfy Option A of Part 6 (Interactive Project Feature). A modal skeleton with backdrop positioning, visibility classes, and a close event listener. Added keyboard navigation handlers (pressing Escape key) and disabled background scrolling when open. Yes, tested across mobile and desktop viewports smoothly.
